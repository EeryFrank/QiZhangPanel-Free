# 七章控制面板 · 免费版

原生 Windows Minecraft 服务器控制面板，由 [EeryFrank](https://github.com/EeryFrank) 开发。界面使用 Windows Forms，后台通过本机标准输入输出通信。

本仓库是独立免费版源码，版本 **2.5.7**。提供单服务器的日常管理，不需要联网激活或安装密钥。

## 下载

- [GitHub 安装包与便携包](https://github.com/EeryFrank/QiZhangPanel-Free/releases/latest)
- [GitLab 安装包与便携包](https://gitlab.com/EeryFrank/QiZhangPanel-Free/-/releases)

安装版可选择安装位置；便携版解压到可写目录后运行。Release 的 `SHA256SUMS.txt` 用于核对下载文件。使用源码时，请按 [构建说明](docs/BUILD.md) 自行构建。

## 功能

- 本地账号、记住账号与自动登录；一份安装管理一台服务器。
- 新建服务端、导入服务器 ZIP、绑定已有文件夹，识别启动项目和 Java 版本。
- 启动、正常停服、通知后重启、保存世界、控制台日志与命令输入。
- 服务器状态、连接地址、CPU 与内存监测。
- 停服后的手动备份与恢复、服务器配置、启动参数及关闭状态下的监听地址和端口设置。
- 从列表移除服务器或确认后删除服务器目录；退出前检查运行状态。

服务器平台、版本和启动脚本存在差异。面板能识别或安装某个平台，不代表该平台的所有版本、模组组合和任意第三方启动器都已验证。实际验证范围见 [验证记录](docs/VALIDATION.md)。

## 使用条件

目标环境为 64 位 Windows 10/11 和 .NET Framework 4.8；本次实测系统见验证记录。发行包包含 Python 运行组件，无需另装 Python；Java、Minecraft 服务端及第三方启动环境按所选服务端要求另行准备。

首次使用在本机创建管理账号。账户工作区不是 Windows 沙箱，服务器数据仍受文件系统权限约束。导入压缩包不会替你接受 Minecraft EULA；首次启动前需自行阅读并同意。

升级前安全停止服务器并备份数据。安装升级选择原目录；便携升级请按 [使用说明](docs/USAGE.md) 操作。请不要把包含账号、服务器、日志或密钥的工作目录提交到仓库。
