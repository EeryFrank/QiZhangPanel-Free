# 2.5.7 验证记录

本记录只针对独立免费版源码及其重新构建的发行包，不沿用其他程序包的测试结论。

## 环境与已完成检查

- Windows 11 x64，系统版本 10.0.26200；.NET Framework 4.x 编译及运行环境。
- Python 3.13；发行包固定携带 Python 3.13.15 x64 嵌入式运行时，下载后校验 SHA-256。
- Java 命令代理由仓库内源码重新编译，目标为 Java 8 字节码。
- 147 项 Python 回归测试通过；原生面板、安装器、卸载器编译通过。
- 本机标准输入输出 IPC：创建账号、登录、绑定单服务器、拒绝第二台绑定、保存基础配置、安全退出。
- 隔离目录中的 ZIP 导入、Java/平台识别、中文日志、命令管道、RCON 协议及账号散列回归。
- 隔离目录中的停服完整备份、修改测试存档后恢复、解除绑定后保留原目录。
- 打包后的原生 EXE：登录、服务器选择、总览、控制台、服务器设置、备份、账号页面，以及基础/高级软件设置和紧凑窗口布局。
- 安装引擎实际执行：中文与空格目录安装、原目录重复安装、保留账号/服务器/用户额外文件；无效或非免费版标识拒绝写入。
- 安装器展开的全部载荷文件与便携包清单逐一核对，未执行快捷方式、开机启动、注册表登记或卸载操作。

## 验证边界

GUI 检查使用独立账号、测试服务器目录及程序自身的页面遍历和截图入口；没有运行用户的真实游戏服务器，也没有接受新的 Minecraft EULA。协议/导入测试包含构造的核心和压缩包，它们用于验证匹配和边界处理，不等同于每个 Minecraft 版本的完整开服测试。

本次不声称验证了所有服务端平台、所有 Java 发行版、真实玩家联机、外网可达性、大型整合包性能、所有 Windows/DPI/主题组合。识别出平台或生成启动文件不代表游戏已经成功启动，应以实际进程、端口和服务端日志为准。

## 如何复查

按 [构建说明](BUILD.md) 从源码构建并运行测试。`scripts/audit-public-tree.py` 检查公开目录边界和常见敏感内容模式；它不能保证识别未知格式的所有秘密，发布前仍需人工检查。

发行附件的 `SHA256SUMS.txt` 用于核对下载内容。GitHub Actions 的结果独立显示；本地检查通过不等同于远程工作流已经通过。
