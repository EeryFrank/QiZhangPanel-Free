# 免费版使用说明

1. 从 Release 下载安装程序或便携 ZIP，按 `SHA256SUMS.txt` 核对文件。
2. 安装到可写目录，或把便携 ZIP 完整解压后运行 `七章控制面板.exe`。
3. 创建本地管理账号并登录。记住账号和自动登录按软件中的选项设置。
4. 在服务器选择页新建服务端、导入 ZIP 或绑定已有文件夹。导入前确认压缩包确实是服务端而非游戏客户端。
5. 检查识别出的核心、启动项目、Java 路径、内存和工作目录。只有完成启动并有对应运行证据后，才把服务端视为可用。
6. 进入服务器管理页启动，查看控制台输出；可发送服务端支持的命令，并使用正常停服、保存世界和通知后重启。

## 数据与升级

便携目录中的 `data` 保存面板账号及配置，`mcSever` 是默认服务器安装目录。也可能绑定其他位置的服务端，请以设置中的实际路径为准。

升级前先正常停止服务器、退出面板并备份旧目录。便携包应先解压到新的空目录，再按实际安装布局迁移保留的账号/配置和服务器资料；不要把空白示例覆盖现有数据，也不要对运行中的目录直接整包覆盖。独立免费版安装升级可选择原安装位置，完成后核对服务器路径。

2.5.7 是这个独立源码仓库的首个发行版。从旧的共享实现迁移时，建议安装到新的专用目录，重新绑定原服务器文件夹，保留旧面板目录作为回退。安装器不会替你删除旧版多余的程序文件；不要把新包覆盖到其他产品的安装目录。新免费版使用独立的位置登记，不会自动选择其他产品的安装位置。

退出时如仍有服务器运行，按提示安全停服；若关闭外部启动器，面板仍会检查实际进程。出现启动结果不明时，先查看日志和进程状态，避免重复开服。

## 网络和文件

核对监听 IP、端口和路由/防火墙设置，才可判断其他电脑能否连接。显示连接地址不代表外网已经连通。

修改服务端地址、端口和启动配置前先停服。删除时确认目标：从列表移除只解除绑定；永久删除会删除对应服务端目录，须输入界面要求的确认文字。

本版手动备份与恢复均要求服务器已停止，并且没有操作正在进行。备份后应确认备份完成并能读取。重要数据建议同时保存到另一块磁盘或独立备份位置。
